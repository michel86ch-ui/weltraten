# Weltraten

Ein Ratespiel fürs Web im Stil von GeoGuessr: Du landest in einem
Street-View-Panorama irgendwo auf der Welt, kannst dich frei umschauen und
rätst, in welchem Land du bist. Je näher dein Tipp, desto mehr Punkte.

**Spielen: https://michel86ch-ui.github.io/weltraten/**

Kein Konto, keine Installation, keine App. Es braucht einen Browser und
einen Anzeigenamen, der nur auf deinem eigenen Gerät gespeichert wird.

## Spielmodi

**Singleplayer** – 5 Runden für zwischendurch, sofort losspielen.

**Multiplayer** – 10 Runden. Wer eine Partie erstellt, bekommt einen
sechsstelligen Code. Alle, die mit demselben Code spielen, bekommen exakt
dieselben zehn Orte in derselben Reihenfolge und landen anschliessend in
einer gemeinsamen Rangliste. Den Code kannst du weitergeben – nötig ist das
aber nicht: Auf der Startseite stehen alle offenen Partien zur Auswahl,
abgeschlossene darunter. Jede Partie zählt pro Gerät einmal, Nachspielen für
einen besseren Platz gibt es nicht.

## Schweiz-Modus

Ein Drittel der Standorte liegt in der Schweiz. Landest du dort, wechselt
die Auswahl automatisch von der Länderliste auf eine Liste Schweizer Orte –
gefragt ist dann nicht das Land, sondern die konkrete Ortschaft. Weil die
Schweiz um ein Vielfaches kleiner ist als der Rest der Welt, gilt ein
entsprechend engerer Massstab: Hier kosten schon wenige Kilometer daneben
Punkte.

## Punkte

Ein exakter Treffer gibt die vollen 5000 Punkte. Sonst zählt die Distanz
zwischen Tipp und Wahrheit – nah dran gibt fast alles, mit wachsender
Entfernung fällt die Punktzahl rasch ab. Über zehn Multiplayer-Runden sind
damit 50'000 Punkte das Maximum.

## Fair bleiben

Im Panorama kannst du dich frei drehen und zoomen, aber nicht zum
Nachbarbild weiterlaufen. Sonst wäre es meist nur eine Frage der Zeit, bis
ein Ortsschild oder ein Nummernschild ins Bild läuft.

Ausserdem merkt sich das Spiel, welche Orte du schon gesehen hast: Kein
Standort kommt ein zweites Mal, bevor nicht alle anderen einmal dran waren.

## Bild melden

Manche Panoramen sind zu leicht – ein Ortsschild steht direkt im Bild – oder
praktisch unlösbar, etwa Wald ohne jeden Anhaltspunkt. Während einer Runde
gibt es dafür den Button **⚑ Bild melden** mit den Gründen „zu einfach" und
„unmöglich". Gemeldete Standorte werden nachträglich korrigiert.

## Inhalt

Zurzeit 248 Standorte: 165 Länder-Runden aus 55 Ländern und 83 Schweizer
Standorte in 62 Ortschaften.
